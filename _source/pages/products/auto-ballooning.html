The problem

Manual ballooning is slow, and it is wrong more often than anyone admits.

Marking up a drawing by hand takes a qualified engineer hours, introduces transcription errors, and has to be repeated in full every time a revision arrives — because there is no reliable way to tell what changed.

The cost is not only the time. A missed characteristic is a missed inspection, and a missed inspection is a part that ships without being checked.

Key features

What the software does.

Automatic detection

Scans the drawing to identify dimensions, tolerances, GD&T symbols, notes and critical-to-quality attributes, creating a unique characteristic ID for each element.

Smart numbering

Intelligent sequencing with customisable formats — prefixes, suffixes and grouping — plus CTQ highlighting and one-click re-numbering for drawing revisions.

Characteristics table generation

Auto-generates the inspection table with balloon numbers, tolerance values, measurement methods and required instruments.

Revision management

Detects dimension changes between versions, provides side-by-side comparison and maintains revision history with impact analysis.

Documentation output

FAI and PPAP report generation with AS9102 and VDA standard compliance, using customisable templates.

Connected integration

Links directly with Control Plans, PFMEA/DFMEA, MSA, SPC and PPAP within the MAPP ZEN ecosystem.
