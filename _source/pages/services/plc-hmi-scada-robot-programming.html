Deliverables

What you receive.

Code is only part of it. The documentation is what makes the code an asset rather than a dependency.

  • PLC logic developed to IEC 61131-3 with consistent naming conventions
  • HMI and SCADA screen development
  • Recipe management, alarms, historian and data logging
  • Virtual commissioning — emulation and testing before shipment
  • Functional Design Specification (FDS)
  • Software Design Specification (SDS)
  • Test scripts and FAT / SAT protocols
  • Commented source code and backup archive

Our standard: internal PLC & HMI programming guidelines aligned to IEC 61131-3 (languages) and IEC 81346-1 (structures), so the program reads the same regardless of which of our engineers wrote it.
